# LiveSync 🚀

LiveSync is a **full-stack MERN application** that provides **secure authentication** and **real-time collaborative document editing**.  
It is built with **production-grade practices**, including JWT authentication, OTP-based email verification, protected routes, and Socket.IO powered real-time sync.

---

## ✨ Key Features

### 🔐 Authentication & Security
- User Registration & Login
- JWT-based Authentication
- Email Verification using OTP
- Forgot Password & Reset via OTP
- Secure Password Hashing (bcrypt)
- Protected Backend & Frontend Routes

### 📄 Collaboration
- Create & Manage Documents
- Share Documents with Other Users
- Real-time Collaborative Editing
- Socket.IO based live synchronization

### 🧠 Application Architecture
- React Context for Global Auth State
- Express Middleware for Route Protection
- MongoDB Atlas for persistent data storage
- Clean MVC-style backend structure
